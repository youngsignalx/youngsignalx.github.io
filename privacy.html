Privacy Policy

ShortsBot · Last updated: 23 November 2026

ShortsBot is a personal desktop application used only by its owner to upload YouTube Shorts to the owner's own YouTube channel. This policy explains what data the app accesses and how it is handled.

YouTube API Services

ShortsBot uses YouTube API Services. By using ShortsBot you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data the app accesses

  • YouTube upload permission (youtube.upload): used only to upload videos to the channel selected by the account owner, with their title, description, tags and scheduled publish time.
  • YouTube read-only permission (youtube.readonly): used only to search public video titles of popular Shorts, which serve as style examples when writing new titles.

The app does not access, collect or store any other personal data, and it does not access data of any user other than the account owner.

Storage

The OAuth access token is stored only on the owner's own computer (in a local file) so the app can upload videos without signing in every time. No data is sent to or stored on any server operated by ShortsBot.

Sharing

ShortsBot does not sell, share or transfer any Google user data to third parties. Short video transcripts may be sent to an AI text service solely to generate a video title and description; these transcripts contain no Google user data.

ShortsBot's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time on the Google security settings page. Deleting the local token file also removes the app's stored access.
